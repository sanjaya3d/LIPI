# LIPI v1.0.3

Type Singlish in any app and get Sinhala, live, as you type.

This update adds a warning card to the window, for a common problem in Adobe and Microsoft apps when you type in FM Abhaya (legacy) mode.

## What's new

- **Smart quotes card.** In legacy mode, Photoshop, Premiere Pro, Word and PowerPoint can show a strange curl instead of a full stop. FM Abhaya uses the straight apostrophe for the full stop, and those apps change it into a curly "smart quote" after LIPI types it. The window now has a card that tells you to turn smart quotes off. Its **වැඩි විස්තර** button opens the steps in the README.
- **README.** A new "Smart quotes" section with the steps for Photoshop, Premiere Pro, Word and PowerPoint, and a matching FAQ answer.

## Changed

- The window is a little taller (86 px) to fit the card. Everything else in it is the same.

## Download

Download `lipi.exe` below and run it. You do not need to install anything. `lipi-windows.zip` has the same exe in a zip file.

## Updating

Close LIPI, replace the old `lipi.exe` with the new one, and run it. Your settings carry over.

## Notes

- Windows only.
- The exe is not code-signed, so Windows may show a blue "Windows protected your PC" window. Click **More info**, then **Run anyway**. The whole source code is in this repository.
- In an app that runs as administrator, run LIPI as administrator too.
- Turn Sinhala typing off (tap Right Ctrl) before you type a password.
