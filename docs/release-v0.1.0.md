# LIPI v0.1.0

Type Singlish in any app and get Sinhala, live, as you type.

## Highlights

- Works in any Windows app, such as Photoshop, Premiere Pro, Blender, Word and browsers.
- Two output types: Unicode, and FM Abhaya (legacy).
- The word updates after every key, and Backspace works letter by letter.
- In legacy mode, punctuation keys such as ? . : % ! ( ) type the right FM Abhaya codes (US keyboard).
- A key hint page inside the window (Keys button), and `lipi --keys` in a terminal.
- Lives in the system tray. Left click opens the window, right click switches typing on or off.
- One small exe with no installer and no libraries. It uses about 2 MB of RAM.

## Download

Download `lipi.exe` from the files below and run it. You do not need to install anything. `lipi-windows.zip` has the same exe in a zip file.

## Quick start

1. Run `lipi.exe`.
2. Tap Right Ctrl to switch Sinhala typing on or off.
3. Tap Right Shift to switch between Unicode and FM Abhaya output.
4. Type, for example `ammaa` for අම්මා, `sixhala` for සිංහල and `koLaBa` for කොළඹ.

The program creates `settings.txt` in `%APPDATA%\LIPI` on the first run (press Win + R and type `%APPDATA%\LIPI` to open the folder). You can change the two keys there.

## Notes

- Windows only.
- The exe is not code-signed, so some antivirus programs may show a warning.
- In an app that runs as administrator, run LIPI as administrator too.
- Turn Sinhala typing off before you type a password.
