# LIPI: Unicode to FM Abhaya legacy codes.
#
# One entry per line:   <hex code point>[+<hex code point>...]  <legacy code>   // note
# The legacy code is everything after the first space, up to an optional " //" note.
# Lines starting with # are comments. A code point can appear only once.
#
# HOW THE CONVERTER USES THIS FILE
#   1. A syllable is read as: letter, optional conjunct (rakaransaya, yansaya, ...), vowel sign.
#   2. If the whole thing has its own entry (letter+sign, or letter+conjunct+sign), that code
#      is used as it is. This is how the special FM Abhaya glyphs work (ඩ් = â, ඩි = ä, ...).
#   3. Otherwise the syllable is built from the pieces: kombuva signs are written in front
#      of the letter, the rest after it.
#   4. Longest entry wins. Nothing depends on the order of the lines.
#
# SOURCE: the codes come from the FM Abhaya conversion script you sent me, after removing its
# bugs (see the audit list). They are NOT checked against the real font here.
# Check with:  cargo run -- --chart   and paste the last lines into a document set to FM Abhaya.
# To fix a glyph, change or add the line here. Put the file next to the program as
# legacy_map.txt and it is used instead of this one.
